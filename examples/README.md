# Données d'exemple

Tous les fichiers de ce dossier sont **entièrement synthétiques**.

Ils servent uniquement à démontrer :

- la consolidation de trois exports métier hétérogènes ;
- la construction d'un vocabulaire à partir de filières/modules ;
- la normalisation et la tokenisation de CV ;
- le matching booléen et le scoring pondéré explicable.

Aucun CV, nom, identifiant, export, historique ou donnée personnelle provenant du système d'origine n'est inclus.
